# 고해상도 이미지 대응

OpenSeadragon은 Deep Zoom Image (DZI) 타일 기반으로 동작한다. 백엔드에서 준비해야 할 핵심 사항:

## 타일화 적용 기준

| 해상도                 | 픽셀 수         | 타일화 필요성                                       |
| ---------------------- | --------------- | --------------------------------------------------- |
| ~2MP (1920x1080)       | ~200만          | 불필요 — 브라우저가 충분히 처리                     |
| 2~10MP (3000x3000)     | ~1000만         | 선택적 — 네트워크 전송이 병목이면 고려              |
| **10MP+ (4000x4000~)** | **1000만 이상** | **권장** — PNG/JPG 원본 전송 시 수십MB, 렌더링 지연 |
| 50MP+ (8000x8000~)     | 5000만 이상     | 필수 — 브라우저 메모리 제한에 도달                  |

- **브라우저 `<img>` 한계**: 대부분의 브라우저에서 `<canvas>` 최대 크기는 약 16384x16384 (~268MP)이지만, 실질적으로 4096x4096 이상부터 디코딩/렌더링에 수백ms~수초 소요
- **네트워크 관점**: 4000x4000 PNG는 약 20~50MB, 같은 크기 JPG도 5~15MB. 타일화하면 뷰포트에 보이는 영역만 로드하므로 초기 로딩이 수백KB 수준으로 감소
- **권장 임계값**: 한 변 **4000px 이상** (약 10MP+)부터 DZI 타일화 적용. 그 이하는 일반 `<img>` + 줌 팝업으로 충분

```python
# 조건부 타일 생성 예시
TILE_THRESHOLD = 4000  # px

h, w = image.shape[:2]
if max(h, w) >= TILE_THRESHOLD:
    # DZI 타일 생성
    vips_img = pyvips.Image.new_from_file(file_path)
    vips_img.dzsave(output_path, tile_size=256, overlap=1, suffix=".jpg")
else:
    # 일반 이미지 그대로 서빙
    ...
```

## 1. DZI 타일 생성

처리된 이미지를 피라미드 타일로 분할해야 한다. Python에서는 `pyvips` 또는 `deepzoom.py` 사용:

```python
# pyvips 방식 (가장 빠름)
import pyvips

image = pyvips.Image.new_from_file("result.png")
image.dzsave("output/result", tile_size=256, overlap=1, suffix=".jpg")
# → output/result.dzi + output/result_files/ (타일 디렉토리)
```

생성 결과:

```
output/
├── result.dzi              # XML 메타데이터
└── result_files/
    ├── 0/                  # 가장 작은 레벨
    │   └── 0_0.jpg
    ├── 1/
    │   ├── 0_0.jpg
    │   └── 1_0.jpg
    ...
    └── 12/                 # 원본 해상도 레벨
        ├── 0_0.jpg
        ├── 1_0.jpg
        └── ...
```

## 2. 타일 서빙 API

두 가지 방식 중 택 1:

### A) Static 파일 서빙 (간단)

```python
# FastAPI에서 타일 디렉토리를 static으로 마운트
app.mount("/tiles", StaticFiles(directory="output"), name="tiles")

# → GET /tiles/result.dzi
# → GET /tiles/result_files/12/0_0.jpg
```

### B) 동적 API 엔드포인트

```python
@router.get("/dzi/{process_id}/{node_id}.dzi")
async def get_dzi(process_id: str, node_id: str):
    ...

@router.get("/dzi/{process_id}/{node_id}_files/{level}/{col}_{row}.jpg")
async def get_tile(process_id: str, node_id: str, level: int, col: int, row: int):
    ...
```

## 3. batch-tree API 수정

`fullSize: true` 요청 시 결과를 DZI로 변환 후 URL 반환:

```jsonc
// 기존: base64 thumbnail 반환
// 변경: DZI 메타데이터 URL 반환
{
  "nodeId": "abc",
  "dziUrl": "/tiles/abc.dzi", // OpenSeadragon이 사용할 URL
  "executionMs": 42,
}
```

## 4. 필요 패키지

```bash
pip install pyvips
# 또는
pip install deepzoom  # 순수 Python, 느리지만 설치 간편
```

> `pyvips`는 libvips 시스템 라이브러리가 필요하다. Windows에서는 libvips 바이너리를 PATH에 추가하거나, conda로 설치할 수 있다.

```bash
export PATH="/c/Program Files/libvips/bin:$PATH" && python -c "import pyvips; print(f'pyvips {pyvips.__version__}, libvips {pyvips.version(0)}.{pyvips.version(1)}.{pyvips.version(2)}')" 2>&1
```

## 요약

| 항목      | 내용                                   |
| --------- | -------------------------------------- |
| 타일 생성 | `pyvips dzsave` (256x256 타일)         |
| 타일 서빙 | `StaticFiles` 마운트 or 동적 API       |
| API 응답  | `dziUrl` 필드 추가                     |
| 캐싱      | 동일 파일+파라미터 조합 결과 캐싱 권장 |
| 정리      | 임시 타일 파일 TTL 기반 삭제           |

프론트엔드에서는 zoom 팝업에서 `OpenSeadragon({ tileSources: dziUrl })`로 연결하면 된다.
