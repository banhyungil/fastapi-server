# 파일 목록 API 인라인 썸네일 반환

## 목표
파일 목록 조회 시 base64 썸네일을 인라인으로 함께 반환하여 N+1 요청 문제를 해결한다.

## 구현 단계

### 1. 썸네일 생성 래퍼 함수 추가
- **파일**: `app/services/image_processing_service.py`
- **함수**: `generate_thumbnail_base64(file_path: str, size: int = 200) -> str | None`
- 파일 읽기 → `cv2.imdecode` → 기존 `_encode_thumbnail()` 호출
- 파일 없거나 디코딩 실패 시 `None` 반환

### 2. TFile 스키마에 thumbnail_url 필드 추가
- **파일**: `app/schemas/file.py`
- `TFile`에 `thumbnail_url: str | None = Field(None, description="썸네일 base64 data URL")` 추가
- DB 컬럼과 무관한 응답 전용 필드 (Pydantic 응답 모델)

### 3. get_saved_images 엔드포인트 수정
- **파일**: `app/api/endpoints/image_processing.py`
- `get_saved_images()`에서 각 item에 대해 `generate_thumbnail_base64()` 호출
- `TFile.model_validate(item)` 후 `thumbnail_url` 할당

### 4. 프론트 ImageGalleryDialog 수정
- **파일**: `quasar-image-processing/src/components/dialog/ImageGalleryDialog.vue`
- `thumbnailUrl(file)` 함수 제거, `file.thumbnailUrl` 직접 사용

### 5. (선택) 기존 thumbnail 엔드포인트 정리
- **파일**: `app/api/endpoints/image_processing.py`
- `/image-processing/thumbnail/{file_id}` 엔드포인트 — 인라인 방식 전환 후 불필요하면 제거
