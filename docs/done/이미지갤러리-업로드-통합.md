# [백엔드] 이미지 갤러리 기능 확장

## 배경
이미지 갤러리 다이얼로그에서 검색, 삭제, 파일명 수정 기능을 지원하기 위한 백엔드 API 추가/수정.

## 완료 항목

### 인라인 썸네일
- `generate_thumbnail_base64()` 래퍼 함수 (`app/services/image_processing_service.py`)
- `TFile.thumbnail_url` 필드 (`app/schemas/file.py`)
- `get_saved_images`에서 썸네일 생성 (`app/api/endpoints/image_processing.py`)

---

## 구현 예정

### 1. 검색 기능 (파일명, 용량)
- **파일**: `app/repos/file_repo.py` → `get_file_list()`
  - `search: str | None` 파라미터 추가 → `origin_nm ILIKE %search%`
  - `min_size: int | None`, `max_size: int | None` 파라미터 추가 → `size_bytes BETWEEN`
- **파일**: `app/services/file_service.py` → `list_files()`
  - 동일 파라미터 전달
- **파일**: `app/api/endpoints/image_processing.py` → `get_saved_images()`
  - Query 파라미터 추가: `search`, `minSize`, `maxSize`

### 2. 삭제 기능
- **파일**: `app/repos/file_repo.py`
  - `delete_by_id(file_id: str) -> bool` 함수 추가
  - `DELETE FROM t_file WHERE id = %s` + 디스크 파일 삭제
- **파일**: `app/services/file_service.py`
  - `delete_file(file_id: str)` 함수 추가 (파일 조회 → 디스크 삭제 → DB 삭제)
- **파일**: `app/api/endpoints/image_processing.py`
  - `DELETE /image-processing/{file_id}` 엔드포인트 추가

### 3. 파일명 수정 기능
- **파일**: `app/repos/file_repo.py`
  - `update_origin_nm(file_id: str, origin_nm: str) -> FileRow | None` 함수 추가
  - `UPDATE t_file SET origin_nm = %s WHERE id = %s`
- **파일**: `app/services/file_service.py`
  - `rename_file(file_id: str, origin_nm: str)` 함수 추가
- **파일**: `app/api/endpoints/image_processing.py`
  - `PATCH /image-processing/{file_id}` 엔드포인트 추가
  - Body: `{ "originNm": "새 파일명.png" }`
