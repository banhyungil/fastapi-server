# 서비스 레이어 리팩토링

## 네이밍 원칙
- 라우터와 서비스 1:1 매칭 (파일명 복수형 통일)
- 오케스트레이션 서비스는 라우터명과 동일
- 내부 모듈은 역할별 분리

## 라우터 ↔ 서비스 매핑

| 라우터 | 오케스트레이션 서비스 | 내부 모듈 |
|---|---|---|
| `files.py` | `files_service.py` | `operations.py`, `thumbnails.py`, `dzi.py`, `cache.py` |
| `filters.py` | 불필요 (스키마 조회만) | |
| `presets.py` | `presets_service.py` | |
| `processes.py` | `processes_service.py` | |
| `custom_filters.py` | `custom_filters_service.py` | |

## 현재 상태
`image_processing_service.py` — 808줄, 모든 이미지 관련 로직이 집중

## 분리 방안

### 서비스 파일 구조 (목표)
```
app/services/
├── files_service.py          — 파일 CRUD + 처리 오케스트레이션 (라우터 진입점)
├── operations.py             — 순수 필터 연산 함수 + OPERATIONS 매핑
├── thumbnails.py             — 썸네일 생성/조회/삭제
├── dzi.py                    — DZI 타일 생성 + 다운로드
├── cache.py                  — 캐시 디렉토리 관리
├── crop.py                — crop 미리보기 (내부 모듈)
├── presets_service.py        — 프리셋 (기존 preset_service.py 이름 변경)
├── processes_service.py      — 프로세스 (기존 process_service.py 이름 변경)
└── custom_filters_service.py — 커스텀 필터 (기존 custom_filter_service.py 이름 변경)
```

### 1. operations.py — 순수 필터 연산
```
포함:
- 모든 _op_* 함수 (30+개)
- OPERATIONS 매핑 dict
- 헬퍼 함수 (_to_gray, _ensure_odd, _morph_kernel)
- ImageOperation 타입

역할: 입력 이미지 → 필터 적용 → 출력 이미지
의존성: cv2, numpy, schemas/image_processing
예상 라인: ~300줄
```

### 2. files_service.py — 파일 CRUD + 처리 오케스트레이션
```
포함:
- 기존 file_service.py 내용 (insert_file, list_files, find_file_by_id 등)
- process_image (단일 처리)
- process_image_batch_tree (트리 배치 처리)
- _process_chain_to_node (체인 처리)
- StepResult, BatchResult, TreeNodeResult, TreeBatchResult 클래스

역할: 라우터 files.py의 비즈니스 로직 진입점
의존성: operations.py, repos/
예상 라인: ~250줄
```

### 3. thumbnails.py — 썸네일 관리
```
포함:
- save_file_thumbnail, get_file_thumbnail_url, delete_file_thumbnail
- _encode_64_thumbnail
- THUMBNAIL_DIR, THUMBNAIL_SIZE 상수

역할: 썸네일 생성/조회/삭제
의존성: cv2, numpy
예상 라인: ~80줄
```

### 4. dzi.py — DZI 타일 생성
```
포함:
- generate_dzi_for_node, download_node_image
- _save_node_dzi, _save_node_image, _ensure_libvips
- DziResult 클래스, TILE_THRESHOLD 상수

역할: 고해상도 이미지 DZI 생성 + 다운로드
의존성: cv2, pyvips, files_service (_process_chain_to_node)
예상 라인: ~120줄
```

### 5. cache.py — 캐시 관리
```
포함:
- cleanup_cache
- CACHE_DIR, CACHE_TTL_SECONDS, CACHE_MAX_BYTES 상수

역할: 캐시 디렉토리 TTL/용량 관리
의존성: pathlib
예상 라인: ~40줄
```
