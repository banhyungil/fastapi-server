# 테스트 환경 구축

## 1. 패키지 설치

```bash
pip install pytest pytest-asyncio httpx
```

| 패키지 | 용도 |
|--------|------|
| `pytest` | 테스트 러너 |
| `pytest-asyncio` | async 엔드포인트 테스트 |
| `httpx` | FastAPI `ASGITransport` 기반 비동기 TestClient |

## 2. 설정

### pyproject.toml

```toml
[tool.pytest.ini_options]
testpaths = ["tests"]
asyncio_mode = "auto"
```

- `asyncio_mode = "auto"` — `@pytest.mark.asyncio` 데코레이터 없이 async 테스트 자동 인식

## 3. 디렉토리 구조

```
tests/
├── conftest.py                    # 공용 fixture
├── test_image_processing.py       # 업로드, 단일 처리, batch, batch-tree

└── test_dzi.py                    # DZI 타일 생성 (서비스 단위 테스트)
```

## 5. DB 격리 전략

현재 repo 레이어에서 `psycopg.connect()`를 직접 호출하는 구조이므로, 테스트 시 DB 격리 방법을 선택해야 한다.

### 방안

| 방식 | 장점 | 단점 |
|------|------|------|
| **A) 별도 테스트 DB** | 실제 SQL 검증 가능, 가장 신뢰성 높음 | 테스트 DB 생성/마이그레이션 필요, CI 설정 추가 |
| **B) DB 호출 mock** | 빠르고 간단, DB 불필요 | SQL 로직은 검증 불가 |

### 권장: A + B 혼합

- **서비스/API 테스트**: DB mock으로 빠르게 검증 (mock `file_repo`, `process_repo` 등)
- **Repo 테스트** (선택): 별도 테스트 DB로 실제 쿼리 검증

### DB mock 예시

```python
from unittest.mock import patch

@patch("app.services.file_service.get_file_list")
async def test_get_files(mock_get_list, client):
    mock_get_list.return_value = {
        "items": [],
        "has_more": False,
        "next_cursor_uploaded_at": None,
        "next_cursor_id": None,
    }
    resp = await client.get("/api/files")
    assert resp.status_code == 200
    assert resp.json()["items"] == []
```

### 별도 테스트 DB 사용 시

```python
# conftest.py
@pytest.fixture(autouse=True)
```

## 6. 테스트 예시

### API 엔드포인트 테스트

```python
# tests/test_image_processing.py

async def test_upload_image(client, test_image_bytes):
    resp = await client.post(
        "/api/image-processing/upload",
        files={"file": ("test.png", test_image_bytes, "image/png")},
    )
    assert resp.status_code == 200
    data = resp.json()
    assert "id" in data
    assert data["mimeType"] == "image/png"


async def test_batch_tree(client, test_image_bytes):
    import json

    steps = json.dumps([{
        "nodeId": "n1",
        "prcType": "gaussianBlur",
        "parameters": {"kernelSize": 5},
        "parentId": None,
    }])
    resp = await client.post(
        "/api/image-processing/batch-tree",
        data={"steps": steps, "fileId": "test-file-id"},
        files={"file": ("test.png", test_image_bytes, "image/png")},
    )
    assert resp.status_code == 200
    data = resp.json()
    assert len(data["results"]) == 1
    assert data["results"][0]["nodeId"] == "n1"
```

### 서비스 단위 테스트

```python
# tests/test_dzi.py

def test_save_node_dzi_creates_tiles():
    import shutil
    import numpy as np
    from app.services.image_processing_service import _save_node_dzi, CACHE_DIR

    img = np.random.randint(0, 255, (5000, 5000, 3), dtype=np.uint8)
    url = _save_node_dzi("test-fid", "test-nid", img)

    assert url.startswith("/uploads/cache/test-fid/test-nid.dzi")
    assert (CACHE_DIR / "test-fid" / "test-nid.dzi").exists()
    assert (CACHE_DIR / "test-fid" / "test-nid_files").is_dir()

    shutil.rmtree(CACHE_DIR / "test-fid", ignore_errors=True)


def test_dzi_not_generated_for_small_image():
    from app.services.image_processing_service import TILE_THRESHOLD

    # 3000x3000 → TILE_THRESHOLD(4000) 미만이므로 DZI 생성 안 됨
    assert 3000 < TILE_THRESHOLD
```
