# 리팩토링 포인트

## 프론트엔드

### 1. ImageZoomPopup 분리 (800줄)
현재 하나의 컴포넌트에 4개 모드(explore/crop/compare/timeline) + 사이드패널 + crop 관리 + 필터 관리가 모두 포함.

**분리 방안:**
- `ZoomSidePanel.vue` — 필터 선택, crop 목록, steps 아코디언, 캔버스 반영 버튼
- `CropManager.ts` — composable로 crop CRUD + activeCrop 상태 관리
- `PreviewManager.ts` — composable로 applyFilters/loadTimeline + abort 관리
- `ImageZoomPopup.vue` — 레이아웃 + 모드 전환만 담당

### 2. ImgPrcPage 분리 (1258줄)
노드 플로우, 프리셋, 프로세스, 줌 팝업, 원본 이미지 관리가 한 파일에 집중.

**분리 방안:**
- `useOriginalImage.ts` — composable로 oOrigin 상태 + setOriginalFile + onSelectExistingImage
- `useNodeFlow.ts` — composable로 nodes/edges + addFilterNode/removeFilterNode/relayout
- `useProcessData.ts` — composable로 프로세스 저장/수정/삭제/로드
- `usePresetData.ts` — composable로 프리셋 로드/적용

### 3. OsdViewer 역할 과다 (329줄)
이미지 뷰어 + 네비게이션 + Shift+드래그 영역 선택 + 뷰포트 좌표 추출이 혼재.

**분리 방안:**
- `useRegionSelect.ts` — composable로 Shift+드래그 선택 로직 분리
- OsdViewer는 순수 뷰어 역할만

### 4. 중복 타입 정의
- `CropItem`, `TempStep` 등이 ImageZoomPopup 내부에 정의 → `types/previewTypes.ts`로 분리
- `Viewport`가 `imgPrcType.ts`와 `file.py`(백엔드)에 각각 정의 → 프론트 타입은 한 곳에서 관리

### 5. API 응답 타입 통일
- `previewApply` → `{ imageBase64, executionMs }` JSON
- `previewApplyAll` → `[{ prcType, imageBase64, executionMs }]` JSON
- 두 응답 구조가 유사하지만 별도 인라인 타입 → 공통 타입으로 추출

## 백엔드

### 1. image_processing.py 엔드포인트 파일 분리 (686줄)
단일 처리, 배치 처리, 업로드, DZI, Preview 등 모든 엔드포인트가 한 파일에 집중.

**분리 방안:**
- `endpoints/image_processing.py` — 단일/배치 필터 처리
- `endpoints/image_upload.py` — 업로드, 갤러리 조회, 삭제, 이름변경
- `endpoints/preview.py` — preview crop/apply/apply-all/delete

### 2. preview_service.py 내 import 정리
- `import time as _time`이 함수 내부에 존재 → 모듈 상단으로 이동
- `import base64`가 엔드포인트 함수 내부에 존재 → 모듈 상단으로 이동

### 3. image_processing_service.py 크기
- 전체 서비스가 하나의 파일 → DZI 관련, 썸네일 관련, 배치 처리를 별도 모듈로 분리 검토

### 4. 캐시 관리 통합
- DZI 캐시 (`uploads/cache/{fileId}/`)
- Preview 캐시 (`uploads/cache/{fileId}/preview/`)
- 썸네일 캐시 (`uploads/thumbnails/`)
- 각각 별도로 관리 → 캐시 매니저로 통합하여 TTL/용량 관리 일원화

### 5. 에러 처리 표준화
- `ValueError` → 400, `RuntimeError` → 500 패턴이 모든 엔드포인트에서 반복
- `AppError` 커스텀 예외가 있지만 preview에서는 미사용 → 통일
