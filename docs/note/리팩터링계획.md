# 이미지 처리 서비스 재정의 계획

## Context

현재 서비스는 `kernel_size` 하나만 파라미터로 받을 수 있고, 나머지 값들(sigmaColor, threshold, beta 등)은 하드코딩되어 실험이 불가능하다. 또한 MD에 정의된 14개 필터가 미구현 상태다. 모든 필터의 OpenCV 파라미터를 조절 가능하게 하고, 미구현 필터를 추가한다.

---

## 1. 핵심 설계: 파라미터 전달 구조

```
Client → Form { prcType, parameters: JSON string }
       → Endpoint (JSON 파싱)
       → Service (Pydantic 모델로 검증 + 기본값 적용)
       → _op_xxx(image, params)
```

- **필터별 Pydantic 파라미터 모델**을 서비스 내부에 정의
- `PARAM_MODELS: dict[PrcType, type[BaseModel]]`로 prcType → 파라미터 모델 매핑
- `model_validate(raw_dict)`로 검증 + 기본값 자동 적용
- 기존 `inspect.signature()` 분기 + `DEFAULT_KERNEL_SIZES` 제거

### 2.2 `app/services/image_processing_service.py` (핵심)

#### 2.2.1 파라미터 모델 정의

각 필터(또는 필터 그룹)별 Pydantic 모델. 기본값이 곧 현재 하드코딩된 값을 대체한다.

| 모델 | 대상 필터 | 필드 (기본값) |
|------|-----------|---------------|
| `NoParams` | prewitt, roberts, histogramEqualization | (없음) |
| `KernelParams` | blur, medianBlur | kernelSize(5) |
| `SobelParams` | sobel | kernelSize(3), dx(1), dy(1), scale(1.0) |
| `LaplacianParams` | laplacian | kernelSize(3), scale(1.0), delta(0.0) |
| `CannyParams` | canny | threshold1(100.0), threshold2(200.0), apertureSize(3) |
| `GaussianBlurParams` | gaussian, gaussianBlur | kernelSize(5), sigmaX(0.0) |
| `BilateralFilterParams` | bilateralFilter | d(9), sigmaColor(75.0), sigmaSpace(75.0) |
| `BoxFilterParams` | boxFilter | kernelSize(5) |
| `BrightnessParams` | plus | alpha(1.0), beta(40.0) |
| `BrightnessParams` | minus | alpha(1.0), beta(-40.0) |
| `GammaParams` | gamma | gamma(1.0) |
| `ThresholdParams` | binary, inverse, tozero, tozeroInverse, truncate, otsu | thresholdValue(127), maxValue(255) |
| `AdaptiveThresholdParams` | adaptive | maxValue(255), adaptiveMethod("gaussian"), blockSize(11), c(2.0) |
| `ContourParams` | findContour, convexHull, boundingBox | thresholdValue(127), color([0,255,0]), thickness(2) |
| `MorphologicalParams` | erosion, dilation, opening, closing | kernelSize(5), kernelShape("rect"), iterations(1) |

#### 2.2.2 함수 시그니처 통일

```python
# Before: 시그니처가 제각각
def _op_sobel(image, kernel_size): ...
def _op_prewitt(image): ...

# After: (image, params) 통일
def _op_sobel(image: np.ndarray, params: SobelParams) -> np.ndarray: ...
def _op_prewitt(image: np.ndarray, params: NoParams) -> np.ndarray: ...
```

#### 2.2.3 신규 필터 14개 구현

| prcType | OpenCV 핵심 함수 | 설명 |
|---------|------------------|------|
| `canny` | `cv2.Canny()` | 다단계 엣지 검출 |
| `roberts` | `cv2.filter2D()` | 2x2 Roberts cross 커널 |
| `boxFilter` | `cv2.boxFilter()` | 정규화 옵션 있는 박스 필터 |
| `convexHull` | `cv2.convexHull()` + `cv2.drawContours()` | 윤곽선의 볼록 껍질 |
| `boundingBox` | `cv2.boundingRect()` + `cv2.rectangle()` | 윤곽선의 외접 사각형 |
| `gamma` | `cv2.LUT()` | 감마 룩업 테이블 |
| `histogramEqualization` | `cv2.equalizeHist()` | 밝기 분포 균등화 |
| `truncate` | `cv2.threshold(THRESH_TRUNC)` | 임계값 초과 클리핑 |
| `otsu` | `cv2.threshold(THRESH_OTSU)` | 자동 임계값 |
| `adaptive` | `cv2.adaptiveThreshold()` | 로컬 적응형 이진화 |
| `erosion` | `cv2.erode()` | 침식 |
| `dilation` | `cv2.dilate()` | 팽창 |
| `opening` | `cv2.morphologyEx(MORPH_OPEN)` | 열기 (침식→팽창) |
| `closing` | `cv2.morphologyEx(MORPH_CLOSE)` | 닫기 (팽창→침식) |

#### 2.2.4 `process_image()` 리팩터링

```python
def process_image(
    prc_type: PrcType,
    image_bytes: bytes,
    parameters: dict[str, Any] | None = None,
) -> bytes:
    # ... image decode ...
    op = OPERATIONS[prc_type]
    param_cls = PARAM_MODELS[prc_type]
    params = param_cls.model_validate(parameters or {})  # 검증 + 기본값
    processed = op(image, params)
    # ... encode ...
```

#### 2.2.5 제거 대상

- `DEFAULT_KERNEL_SIZES` dict → Pydantic Field default로 대체
- `import inspect` → 더 이상 시그니처 검사 불필요

### 2.3 `app/api/endpoints/image_processing.py`

#### POST `/image-processing` 변경

```python
async def img_processing(
    file: UploadFile,
    prc_type: PrcType = Form(alias="prcType"),
    parameters: str | None = Form(None),          # 신규: JSON 문자열
    kernel_size: int | None = Form(None, alias="kernelSize"),  # 하위 호환
):
    # 1. parameters JSON 파싱
    params_dict = json.loads(parameters) if parameters else None

    # 2. 하위 호환: kernelSize만 보낸 경우
    if params_dict is None and kernel_size is not None:
        params_dict = {"kernelSize": kernel_size}

    # 3. 서비스 호출
    result = process_image(prc_type, image_bytes, params_dict)
```

- `pydantic.ValidationError` 캐치 → 400 응답 추가

#### POST `/image-processing/save` 변경

- `parameters` Form 필드 추가
- DB 저장 시 `options`에 `parameters` dict 포함

## 3. 하위 호환성

```
기존 요청: prcType=blur, kernelSize=7
→ endpoint에서 parameters={"kernelSize": 7}로 변환
→ KernelParams.model_validate({"kernelSize": 7}) → kernel_size=7
→ 기존과 동일 결과
```

`kernelSize` Form 필드는 deprecated로 유지, 향후 제거.

## 6. 검증 방법

1. 기존 필터 + `kernelSize`만 전송 → 기존과 동일한 결과 확인 (하위 호환)
2. 기존 필터 + `parameters` JSON 전송 → 파라미터 변경 효과 확인
   - 예: `bilateralFilter` + `{"sigmaColor": 150}` → 더 강한 블러
3. 신규 필터 테스트 → 각 필터별 정상 출력 확인
4. 잘못된 파라미터 전송 → 400 에러 + 검증 메시지 확인
   - 예: `{"kernelSize": -5}` → ValidationError
